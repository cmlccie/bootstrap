# Session 1: The FRC Stack and Your First Commit

!!! warning "Draft"

    This session is under construction. The outline below is a draft and will change.

## 🎯 Objectives

By the end of this session you will be able to:

- Name the major hardware and software components of an FRC robot system and explain how they connect.
- Sign in to your own GitHub account as a member of the team's GitHub organization.
- Open the bootcamp repository in a GitHub Codespace.
- Create a branch, make a change, commit it, and push it to GitHub.

## 🗓️ Agenda

1. **Welcome and goals** - what this bootcamp is (and is not).
2. **The FRC stack** - laptop, Driver Station, field/FMS, radio, roboRIO, motor controllers, sensors, and the software that runs on each.
3. **GitHub setup** - create your account, join the organization, tour the `2026-bootcamp` repository.
4. **Your first Codespace** - open the repository in a Codespace and look around VS Code.
5. **Your first commit** - create a branch, make a change, commit, and push.
6. **Wrap up** - what to expect in Session 2.
